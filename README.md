# 沪深300 K线

跨电脑浏览器和 iPhone Safari（可添加到主屏幕）使用的沪深 300 指数 K 线网页应用。登录后，画的线、方框和当时的周期会保存到云端并在两端同步。

主界面只有：上方 K 线图、下方 MACD（12/26/9）、底部连续周期滑块。工具栏提供画线、画框、删除、保存和改颜色。

## 功能

- 邮箱 + 密码注册 / 登录 / 退出，密码加盐哈希存储，登录态用 httpOnly cookie 保持。
- K 线可缩放、平移（鼠标滚轮、拖动；手机上单指拖动、双指缩放）。
- **连续周期滑块**（对数刻度，1 分钟到 1 周，1 周按 5 个交易日、共 1200 个交易分钟理解）。拖动时用基础行情实时重聚合成新的 K 线并重算 MACD，不是在固定周期之间跳档。
- **K 线密度滑块**：连续调节一屏显示多少根 K 线（默认约 80 根，范围 20 到最多 500 根，上限随屏宽缩小，保证手机上单根不会过细）。拖动时图表立即变密或变疏，MACD 同步变化。鼠标滚轮、双指缩放也会改密度，并与滑块互相同步。仍可左右平移查看历史。密度与周期、标注一起自动保存并云端同步。
- 画线、画矩形框：按**价格 + 时间**锚定，切换周期后尽量保持位置。
- 画图和拖动端点时，靠近附近 K 线最高价或最低价会吸附到影线。
- 线的两端可单独拖动。框的四角可拖（同时改相邻两边）；四边可单独拖，**拖哪条边只有那条边移动，对边不动**。
- 每条线、每个框可单独改颜色，并随标注一起保存、同步。
- 自动保存（约 1.5 秒防抖）+ 手动保存按钮。保存内容包括全部线/框（坐标、颜色）以及当时周期。

## 环境要求

- Node.js 22+（推荐 24，使用内置 `node:sqlite`，无需额外安装 SQLite）
- 能访问公开行情接口（新浪财经 / 腾讯财经）

## 安装

```bash
cd hs300-chart
npm install
```

可选：复制环境变量文件并修改密钥。

```bash
cp .env.example .env
```

主要变量：

| 变量 | 说明 |
| --- | --- |
| `PORT` | 服务端口，默认 `3000` |
| `JWT_SECRET` | 签署登录 cookie 的密钥，部署时请改成足够长的随机字符串 |
| `CORS_ORIGIN` | 可选。前后端不同源时填写前端地址，多个用逗号分隔 |
| `COOKIE_SECURE` | 设为 `1` 时 cookie 带 Secure（仅 HTTPS）。本地 HTTP 请保持不设置或 `0` |
| `SESSION_DAYS` | 登录有效期（天），默认 30 |
| `DATABASE_URL` | 可选。设置后用户和标注存到 PostgreSQL（云端部署推荐，数据不会因重启丢失）；不设置则使用本地 SQLite。行情缓存始终在本地 SQLite |

## 运行

开发模式（后端 `3000`，前端 Vite `5173`，`/api` 会代理到后端）：

```bash
npm run dev
```

浏览器打开：http://127.0.0.1:5173

生产模式（先构建前端，再由后端同时提供页面和 API）：

```bash
npm run build
npm start
```

浏览器打开：http://127.0.0.1:3000

自测：

```bash
npm run selftest
```

默认假设服务已在 `http://127.0.0.1:3000` 运行。也可指定：

```bash
BASE_URL=http://127.0.0.1:3000 npm run selftest
```

## iPhone 使用

1. 电脑和手机能访问同一地址（同一局域网下可用电脑的局域网 IP，例如 `http://192.168.x.x:3000`）。
2. 用 Safari 打开该地址并登录。
3. 点击分享 →「添加到主屏幕」，即可全屏使用。
4. 在电脑上画的线和框，手机刷新或重新打开后会同步过来（需同一账号）。

## 行情数据说明

服务端会从公开接口拉取并缓存：

- **1 分钟**：优先新浪财经，约 1500 根（大约 6–7 个交易日），短周期必须由此重聚合。
- **5 分钟 / 60 分钟 / 日线**：用于当滑块周期正好是 5、60、240 分钟的倍数时提供更长历史（滑块拉到日线、周线时仍有足够 K 线）。
- 备用源：腾讯财经。缓存写入本地 SQLite，默认约 1 分钟刷新一次。

A 股交易时段按 9:30–11:30、13:00–15:00 处理；周期小于等于 120 分钟时，K 线不会跨过午休。

## 项目结构

```
hs300-chart/
  client/          # Vite + React + TypeScript 前端
  server/          # Express + SQLite 后端
  server/data/     # 本地数据库（用户、标注、行情缓存）
  scripts/         # 自测脚本
```

## 部署到 Render（免费）

仓库根目录的 `render.yaml` 描述了一个免费 Web 服务（新加坡区）加一个免费 PostgreSQL。手动创建时参数：

- Runtime：Node；Build：`npm ci && npm run build`；Start：`npm start`；Health check：`/api/health`
- 环境变量：`NODE_VERSION=24`、`COOKIE_SECURE=1`、`JWT_SECRET`（随机长字符串）、`DATABASE_URL`（Render Postgres 的 Internal URL）

免费 Web 服务闲置约 15 分钟会休眠，再次打开需要等待约 30–60 秒；免费 PostgreSQL 创建 30 天后到期（需升级或重建）。

## 已知限制

- 1 分钟历史长度取决于公开接口（目前大约一周），不是「任意怪周期」都有多年历史。周期为 5/60/240 分钟的倍数时会改用更长的 5 分钟、60 分钟或日线。
- 第一版不做成交量、其他指标、更多画图工具、实时推送、分享链接或原生 App。
- 行情来自第三方公开接口，盘中可能偶发延迟或短暂失败；失败时会尽量返回缓存。
